# 项目资料（Sources）

> 状态：Active
> Owner：RAG 团队
> Last Updated：2026-08-03
> Scope：v3 已绑定项目的资料发现、受控索引和来源浏览
> Related：`agent-tasks-and-runs.md`、`../requirements/agent-product-v3.md`、`../design/v3-sources-contract.md`

## 1. 用户能力

用户可以在已添加的 v3 项目中执行一次资料扫描，查看已受管的资料源和文件清单。扫描只读取已绑定项目根内的受支持文本文件；它不会修改项目文件、上传到外部服务、执行代码或读取符号链接目标。

资料列表只显示相对路径、类型、大小、校验摘要和索引状态。列表、事件和产物不显示文件正文、绝对项目路径、API Key、令牌或连接器密钥。

## 2. 首段边界

- Sources 首段只支持 `project_root`，即创建 v3 Project 时已确认的本地根目录；GitHub、Notion、Obsidian 和任意 URL 连接器不属于本段。
- 扫描跳过 `.git`、依赖、构建、缓存和虚拟环境目录，不跟随任何符号链接，并受条目、单文件大小和总内容大小限制。
- 同一项目重复扫描更新已有资料快照，不产生重复 `sources` 或同相对路径 `documents`。
- 源文件读取失败或超出限制时保留明确的失败/跳过原因；单个文件失败不阻断其他可读文件。
- 只有遍历完整且没有读取失败的扫描才删除缺失 Documents；截断或存在读取失败时仍更新已成功读取的资料，但保留旧 Documents，避免不完整快照改变资料事实指纹。
- 资料改变不会静默改写已经完成的 Run 或生成的 Artifact；后续洞察、检索和工作流只能明确使用其已记录的资料版本。

## 3. 当前实现状态

v3 已开放已绑定项目根的扫描、Sources 列表和 Documents 元数据列表；平行 React 项目页可触发扫描、展示真实来源和相对路径。扫描和列表不返回正文或绝对路径。

文档正文预览、手工资料编辑、外部连接器和向量化/检索仍未实现；资料快照概览由独立的 `project-insights.md` 定义。受限工作流执行和 Artifact 导出已在独立合同中开放，但不能替代 Sources 的资料快照边界。
