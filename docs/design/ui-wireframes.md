# UI 页面结构说明

> 状态：Active
> Owner：RAG 团队
> Last Updated：2026-08-01
> Scope：当前 `App.vue` 可达界面、覆盖层和已知未接线边界
> Related：`page-module-contract.md`、`component-api-contract.md`、`frontend-backend-contract-check.md`

## 1. 当前可达结构

当前不使用 `vue-router`。`frontend/src/App.vue` 以 `appState.currentView` 切换四个主视图：

| 视图键 | 组件 | 用户任务 |
|--------|------|----------|
| `coach` | `WorkbenchView` | 来源问答、会话、依据、逐点学习入口和高级诊断 |
| `learning-map` | `LearningMapView` | 项目分析、知识覆盖、技能映射、评估与逐点学习入口 |
| `learning-plan` | `LearningPlanView` | 草稿、确认版、进度、确认任务学习和发布入口 |
| `settings` | `SettingsView` | 回答、资料说明、Obsidian 和外观设置 |

“资料”打开 `LibraryModal`，不改变 `currentView`。来源、评估、逐点学习和发布分别使用 `CoachSourceDrawer`、`CoachAssessmentOverlay`、`CoachLearningSessionOverlay`、`ObsidianPublicationDialog` 覆盖层；关闭后保留原项目和主视图。

`LibraryView`、`AssessmentView` 等源码兼容组件没有被当前 `App.vue` 装配，不能因为文件存在就写成可达页面。

## 2. 全局布局

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 工作区侧栏           │ 当前主视图                           │ 覆盖层 │
│ - 教练               │ coach / learning-map                │ 来源   │
│ - 学习地图           │ learning-plan / settings            │ 评估   │
│ - 学习计划           │                                      │ 学习   │
│ - 资料（弹窗）       │                                      │        │
│ - 设置               │                                      │        │
│                      │                                      │ 发布   │
│ - 项目与聊天线程     │                                      │        │
└─────────────────────────────────────────────────────────────────────┘
```

760px 以下侧边栏默认折叠，可从顶部按钮重新打开。折叠只改变布局，不改变当前项目、线程或视图。

## 3. 教练

```text
┌─────────────────────────────────────────────────────────────────────┐
│ [问题输入与发送/取消]                                               │
│ [聊天线程]                                   [依据抽屉：默认收起]    │
│ 用户问题 / 流式回答 / 反馈                  来源、检索复盘、工具、  │
│                                             模型对比                │
└─────────────────────────────────────────────────────────────────────┘
```

已接线：

- 提交问题、关闭当前 SSE、加载聊天、删除/清空消息；
- `token` 增量显示，`done` 刷新完整回答/来源/消息，`answer_error` 显示失败；
- 回答反馈、检索设置与调试、检索复盘、只读 Agent 工具和运行记录；
- 从教练打开资料弹窗、Coach 评估覆盖层或逐点学习覆盖层；有活动学习会话时输入工具显示恢复入口。

可见但未形成完整行为：

- 侧边栏“搜索线程”输入框没有绑定过滤状态；
- “上传临时文件”“整理要点”“常用指令”按钮没有动作；
- “连接工具”事件没有从 `WorkbenchView` 接到 `App.vue`；
- “回答”“深度”下拉框没有绑定请求参数；
- 资料弹窗的文档选择用于预览，不会把所选文档/集合加入问答过滤条件；
- 问题输入区直接触发模型对比时没有提供两个 Profile ID，完整对比需要在高级模型区域选择配置。

## 4. 学习地图

```text
┌─────────────────────────────────────────────────────────────────────┐
│ [分析项目] [刷新]                                                    │
│ [项目概览：知识点、已验证数、覆盖]                                  │
│ [项目知识点：学习/评估/来源]   [技能映射：学习/评估/来源]           │
│ [最近评估与有效学习 attempt]                                       │
└─────────────────────────────────────────────────────────────────────┘
```

- 未选项目、无分析、加载、错误、空结果和 `stale` 都有独立状态。
- 知识点与有项目证据的技能节点可打开来源、发起评估或开始逐点学习；来源、状态和可用性来自服务端，前端不重算。
- `stale` 时历史结果只读，禁止新评估和逐点学习，用户需要重新分析。
- 技能映射只描述当前项目，不显示职业等级或跨项目总分。

## 5. 学习计划

```text
┌─────────────────────────────────────────────────────────────────────┐
│ [刷新] [生成草稿]                                                    │
│ [草稿 | 已确认]                                                      │
│ 任务：目标 / 来源 / 练习 / 完成标准 / 时长 / 状态 / 排序            │
│ 确认版 learning 任务：[开始学习 / 继续学习]                         │
│ [保存草稿] [确认] 或 [保存进度]                                     │
│ [预览发布到 Obsidian]                                                │
└─────────────────────────────────────────────────────────────────────┘
```

- 草稿按服务端能力标志开放结构编辑、排序和确认。
- 确认版结构只读，只允许更新进度；`learning` 任务可打开绑定该任务的逐点学习会话。会话自动联动后刷新计划，但前端不自行计算任务状态。
- 分析 `stale`、页面忙碌或正在保存时禁用任务学习入口；并发冲突必须显示，不能静默覆盖。
- 无活动 Obsidian 连接时发布入口转到设置；有连接时先打开发布预览。
- 确认发布后显示 `queued`，不能在插件回传前显示成功。

## 6. 逐点学习覆盖层

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 逐点学习                  [进度：当前 / 已完成 / 总数]      [关闭] │
│ [当前知识点讲解] [真实来源路径与摘录]                              │
│ [一道当前练习]                                                     │
│ SQL：结构化样例表 / 列类型 / NULL / 固定样例行                     │
│ [原始多行答案或 SQL] [提交]                                       │
│ [本次得分、具体反馈、结果预览、证据资格]                           │
│ [开始讲解 / 开始本题 / 重试 / 查看答案 / 下一知识点 / 放弃]       │
└─────────────────────────────────────────────────────────────────────┘
```

- 覆盖层只依据服务端 `current_step / current_exercise / allowed_actions` 展示当前阶段，不预载未来步骤或前端推导重试规则。
- SQL fixture 只展示公开的 Schema 与固定合成样例行；期望结果、必要语义、资源限制和参考答案在 reveal 前不可见。
- SQL 文本只以 `trim()` 判断是否为空，提交时保留原始换行和缩进；一次提交生命周期内复用同一幂等键并禁用重复提交。
- 每次提交展示具体反馈和受限结果预览。答案揭示后明确提示同题后续 attempt 不计独立掌握证据。
- 版本冲突或请求失败后读取服务端最新会话恢复；来源过期只读、正常完成和主动放弃使用不同文案。
- 覆盖层关闭后不修改 `currentView`、当前项目或会话记录；工作区重新加载时可恢复活动会话，但不自动打开覆盖层。

## 7. 资料弹窗

```text
┌─────────────────────────────────────────────────────────────┐
│ [加入资料] [选择资料]                              [关闭]    │
│ 笔记 / URL / 文件 / 文件夹 / GitHub / Obsidian Vault        │
│ 导入状态与错误                                               │
│ 集合筛选 / 文档列表 / 文档预览                               │
│ Obsidian 连接状态与设置入口                                  │
└─────────────────────────────────────────────────────────────┘
```

- 笔记、文件、文件夹、GitHub 仓库和一次性 Vault 导入调用真实后端接口。
- URL 摘录表单当前只发 `{url}`，API helper 要求 `url/title/content`，因此该入口会在前端校验失败。
- 选择资料时侧栏临时进入 `workspace-select`，关闭弹窗后恢复线程侧栏；当前实际列表加载仍以选中项目状态为边界。
- Obsidian Vault 一次性导入与插件连接/发布必须使用不同文案。

## 8. 设置

| 页签 | 当前状态 |
|------|----------|
| 回答 | 全局 LLM 设置、模型 Profile、项目 Prompt 预设已接 API |
| 资料 | 位置选择、备份、恢复按钮禁用，不得显示伪成功 |
| Obsidian | 连接列表、撤销和一次性配对码已接 API |
| 外观 | 保留入口，主题切换未接入 |

设置响应不回显明文 Key/Token，但兼容全局 LLM 保存会把用户输入 Key 写入用户应用数据 `.env`。当前 Vue 没有应用认证凭证 UI；启用 `RAG_AUTH_ENABLED=1` 后不能把此页当作登录入口。

## 9. 状态展示约束

| 场景 | 必须展示 | 禁止展示 |
|------|----------|----------|
| 未选项目 | 选择/创建项目引导 | 空白成功状态 |
| 无文档 | 打开资料入口 | 伪造示例来源 |
| 无检索命中 | 明确缺少来源和可执行下一步 | 模型补造引用 |
| API 不可用 | 检查后端/刷新提示 | 将网络失败写成空数据 |
| 分析过期 | `stale` 和重新分析入口 | 继续把历史结果称为当前 |
| 学习会话终态 | 独立显示完成或放弃；保留历史 attempt | 把正常终态误报为来源过期 |
| SQL 练习 | 固定练习数据、只读边界、具体错误或结果差异 | 暗示连接正式数据库或把执行失败显示为正确 |
| 发布排队 | 等待插件执行 | “已写入 Vault” |
| 未接线控件 | 禁用、说明或列入 BACKLOG | 仅凭可见按钮宣称能力完成 |
