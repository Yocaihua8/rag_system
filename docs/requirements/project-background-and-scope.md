# 项目背景与范围

> 状态：Active
> Owner：RAG 团队
> Last Updated：2026-08-01
> Scope：Knowledge Island 的产品定位、目标用户、目标与非目标
> Related：`functional-modules.md`、`use-cases.md`、`version-scope.md`、`../features/README.md`

## 1. 背景

个人开发者和编程学习者通常同时维护代码、架构说明、需求记录、测试和个人笔记。通用知识库可以帮助检索资料，却不容易持续回答：

- 当前项目的关键结构、流程和约束是什么；
- 用户对哪些项目知识已有评估证据，哪些仍未验证；
- 当前项目关联到哪些可复用技术主题；
- 下一步应该阅读、练习和验证什么。

Knowledge Island 定位为本地优先的项目知识教练：把用户明确导入的项目代码、文档和笔记转化为可检索来源，以来源约束问答、项目分析、评估和学习计划，并允许用户把确认后的成果受控发布到 Obsidian。

## 2. 目标用户

| 用户 | 主要目标 | 典型场景 |
|------|----------|----------|
| 独立开发者 | 快速恢复和验证项目理解 | 接手旧项目，梳理模块、接口、测试和约束 |
| 编程学习者 | 用真实项目检验学习成果 | 完成项目后定位尚未掌握的知识点 |
| 个人知识管理者 | 连接项目资料与长期笔记 | 导入 Obsidian 内容，并发布经确认的学习成果 |

系统以本机单用户为边界，不把共享 API Key 或项目 ID 解释为团队账号、租户或成员权限。

## 3. 产品目标

```text
创建项目并导入资料
  -> 生成有来源的项目理解
  -> 围绕当前项目问答
  -> 评估项目知识
  -> 查看知识覆盖与技能映射
  -> 生成、编辑并确认学习计划
  -> 经预览和确认后发布到 Obsidian
```

产品遵守以下原则：

- **项目知识优先**：结论只描述当前项目和当前来源版本。
- **来源可追溯**：回答、知识点、技能映射、评估和学习任务都应能回到真实来源；证据不足时明确降级。
- **学习而非职业评价**：技能树用于组织学习主题，不输出岗位匹配、职业等级或跨项目排名。
- **本地基线可用**：未配置 LLM 时仍保留本地检索、来源片段回答、规则分析与规则评估。
- **模型只做可选增强**：外部模型不能绕过来源约束，也不能把推断伪装为项目事实。
- **写回由用户控制**：Obsidian 发布必须经过预览、确认、受管文件校验和结果回传。

## 4. 当前产品边界

当前范围包括：

- 项目创建、重命名、删除、摘要、导出与恢复；
- 本地目录、浏览器文件/文件夹、文本笔记、URL 摘录、受控网页抓取、Notion ZIP、GitHub 仓库和 Obsidian Vault 导入能力；
- 文档、集合、导入批次、分块、混合检索、来源问答、聊天和回答反馈；
- 可选 Ollama 或 OpenAI-compatible 模型、模型 Profile、项目 Prompt 预设、检索调试与复盘；
- 项目分析、知识点、技能映射、定向评估、覆盖视图和版本化学习计划；
- 桌面承载和独立 Obsidian 插件的配对、增量事件与受控发布；
- 本地 Web、Tauri 和双服务 Docker 运行形态。

“后端存在接口或源码”不等于“当前 Vue 主路径可达”。当前可达性与未接线边界以 [`../design/frontend-backend-contract-check.md`](../design/frontend-backend-contract-check.md) 为准。

## 5. 数据与兼容边界

- 当前默认数据根为 `runtime/v2/`，SQLite 为 `runtime/v2/app.db`。
- 旧代际数据不会被自动迁移、删除或覆盖；用户需要通过当前支持的导入或项目导出/恢复能力显式处理资料。
- 1.x 导入、聊天和基础评估接口作为兼容契约保留；旧 PySide6 桌面实现不属于当前运行入口。
- 所有业务数据以 `project_id` 隔离；当前没有跨项目知识库或跨项目能力总览。

## 6. 非目标

- 多用户、团队空间、多租户 SaaS、云同步或默认公网部署；
- 职业评价、招聘筛选、绩效考核、证书体系或跨项目个人画像；
- 完整 AST 调用图、全语言静态分析平台或 IDE 替代品；
- Agent 写代码、执行 shell、修改项目文件或运行任意命令；
- 无需确认的 Obsidian 自动写回、自动冲突合并或覆盖用户自有笔记；
- 移动端应用、Obsidian 移动端插件或插件市场发布承诺；
- 把可选 LLM、Qdrant、Cross-Encoder 或 PDF 解析依赖变成基础闭环的强制条件。

未完成事项只进入 [`../BACKLOG.md`](../BACKLOG.md)，不在本文件混写未来设计。
