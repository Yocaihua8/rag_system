```markdown
# ADR-005 导出任务使用对象存储而非本地磁盘

> 状态：Accepted
> Date：2026-04-17
> Owner：张三
> Scope：导出产物存储与下载边界
> Related：`../features/order-export.md`、`../design/architecture-overview.md`

## 1. 背景

订单导出任务产物 > 500MB，放本地磁盘会导致多实例下载不一致，且清理依赖定时任务，易遗留。

## 2. 决策结论

导出产物统一写入对象存储（S3 兼容），客户端通过预签名 URL 直接下载。

## 3. 决策原因
1. 多实例天然一致
2. TTL 策略由对象存储托管，无需自建清理
3. 下载带宽不经过应用服务

## 4. 备选方案
### 4.1 方案 A：共享 NFS
- 缺点：单点、扩容成本高
- 未采用原因：团队无运维 NFS 的经验

## 5. 影响
### 5.1 正面影响
- 应用层无状态，可水平扩缩容

### 5.2 负面影响
- 新增对象存储账单（月约 ¥50）

## 6. 后续动作

### 6.1 实施计划
| 项目 | 内容 |
|------|------|
| 实施开始日期 | 2026-04-20 |
| 实施结束日期 | 2026-04-27 |
| 实施负责人 | 张三 |

### 6.2 回滚策略
| 项目 | 内容 |
|------|------|
| 回滚触发条件 | 上线后 48h 内下载成功率 < 99% 或出现数据泄露 |
| 回滚步骤 | 切回本地磁盘分支；清理已生成的对象存储文件 |
| 数据回滚说明 | 已生成但未下载的任务需用户重新发起 |
| 回滚责任人 | 张三 |
| 不可回滚的点 | 用户已成功下载的文件不回收 |

### 6.3 验证方式
- 验证指标：下载成功率、平均下载耗时、对象存储调用失败率
- 观察窗口：上线后 7 天
- 验收标准：成功率 ≥ 99.5%，失败率 ≤ 0.1%
```

### 示例 2：三层架构

下方为一个简化的三层架构决策样例。**复制模板时请删除本附录**。

```markdown
# ADR-006 用户中心采用三层架构

> 状态：Accepted
> Date：2026-04-18
> Owner：张三
> Scope：用户中心内部职责边界
> Related：`../design/system-design-overview.md`、`../design/architecture-overview.md`

## 1. 背景

用户中心当前把参数校验、业务规则、数据库访问混在同一服务类中，导致权限校验重复、测试困难、接口改动容易牵连持久化细节。

## 2. 决策结论

用户中心统一采用三层架构：表现层负责 HTTP 请求与响应；业务层负责资料修改、权限判断与事务控制；数据层负责用户数据持久化与外部依赖访问。

## 3. 决策原因
1. 降低控制器与数据访问直接耦合
2. 让核心业务规则集中在业务层，便于测试
3. 后续若替换存储实现，只影响数据层

## 4. 备选方案
### 4.1 方案 A：继续使用 Controller 直连 Repository
- 优点：改动最少
- 缺点：业务规则继续分散
- 未采用原因：后续维护成本高

### 4.2 方案 B：直接切到六边形架构
- 优点：边界更清晰
- 缺点：当前模块规模较小，改造成本偏高
- 未采用原因：现阶段三层架构已足够满足复杂度

## 5. 影响
### 5.1 正面影响
- 用户中心职责边界更清晰
- 单元测试更容易聚焦业务层

### 5.2 负面影响
- 初期需要拆分类与接口，短期改动量上升

### 5.3 对现有系统的改动点
- 新增 `UserService`
- Controller 只保留请求转换与响应封装
- Repository 访问统一下沉到数据层

## 6. 后续动作
### 6.1 实施计划
| 项目 | 内容 |
|------|------|
| 实施开始日期 | 2026-04-20 |
| 实施结束日期 | 2026-04-24 |
| 实施负责人 | 张三 |

### 6.2 回滚策略
| 项目 | 内容 |
|------|------|
| 回滚触发条件 | 改造后主流程回归失败或接口响应不兼容 |
| 回滚步骤 | 恢复旧控制器与服务实现；撤回三层拆分代码 |
| 数据回滚说明 | N/A，结构未变 |
| 回滚责任人 | 张三 |
| 不可回滚的点 | N/A |

### 6.3 验证方式
- 验证指标：主流程通过率、接口响应兼容性、业务层单元测试覆盖
- 观察窗口：上线后 3 天
- 验收标准：用户中心主流程全部通过，新增业务层测试覆盖关键规则
```
