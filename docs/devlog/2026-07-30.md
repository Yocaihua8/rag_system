## 3. Decisions（临时决策）

- 使用 `minimatch@9.0.8` 兼容覆盖修复传递依赖 → 原因：避免强制替换旧 minimatch 的导入契约，也避免升级到不兼容 CI Node 20 的上游依赖链。
- 本地 CI 证据不得表述为 GitHub Actions 通过 → 原因：远端配额边界和本地验证需要分别留痕。
- Windows NSIS 文件在 Tag/Release 前仅作为本地候选 → 原因：远端功能分支、PR、`main` 合并、`v2.0.0` Tag 和 GitHub Release 均尚未完成。
