## 2. Issues

- **问题**：现行仓库规则和检查器禁止 `docs/devlog/`，与用户最新明确要求冲突。
  **影响**：直接复制模板会使文档门禁失败。
  **当前处理**：只解除 DevLog 禁止项，并为 `YYYY/MM/` 增加专用结构与元数据检查；继续禁止 readiness、preview 和完成 plan 归档。
  **跟踪**：B-172
- **问题**：当前源码仍为 v2 知识教练，v3 文档不能描述为已实现。
  **影响**：产品目标与当前可达行为容易混写。
  **当前处理**：已实现部分明确标为 v3 后端 alpha；v2 当前事实和 Vue 继续保留，未接线目标仍按未实现描述。
  **跟踪**：B-173 至 B-177
- **问题**：本地 venv 与 CI 当前使用 Python 3.11，v3 正式目标为 Python 3.12。
  **影响**：3.11 测试结果不能证明 3.12 兼容性。
  **当前处理**：测试指南分开记录当前验证环境和目标版本，后续需在真实 3.12 环境补跑同一门禁。
  **跟踪**：B-177
- **问题**：首次全量 651 项通过后，独立调度复核发现 `recovery_required` 不确定写步骤未继续占用同项目写槽。
  **影响**：恢复未决时可能继续认领同项目写动作并破坏现场。
  **当前处理**：将恢复中不确定写纳入串行阻塞条件，并增加真实并发认领、跨写类型互斥、读取不受阻塞和恢复锁测试；最终全量增至 653 项并通过。
  **跟踪**：B-173
- **问题**：首次重跑 B-178 关键测试时，仓库 `runtime/test-b178-focused` 临时目录被当前环境拒绝写入。
  **影响**：首轮仅有 4 项无需临时目录的测试执行，其余 38 项在 setup 阶段报 `PermissionError`，不能作为功能失败证据。
  **当前处理**：改用线程可写的独立 visualization 临时目录重新运行；关键 42 项和全量 664 项随后全部通过，未写入 v2/v3 运行数据库。
  **跟踪**：B-178
