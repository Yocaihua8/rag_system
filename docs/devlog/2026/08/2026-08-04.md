## 3. Decisions

- 单 Task 的“活动”状态定义为全部非终态 Run，包括 queued、running、waiting_approval、paused 和 recovering → 原因：这些状态都可继续改变共享 Task 状态，不能与新 Run 并发。
- 不完整扫描的判定仅基于截断或读取失败 → 原因：这两类情形无法证明既有相对路径已不存在；完整扫描继续保持真实删除语义。
