# 资料浏览与分组

> 状态：Active
> Owner：RAG 团队
> Last Updated：2026-08-01
> Scope：当前项目的资料列表、集合筛选、预览与管理可达边界
> Related：`project-space-ingestion.md`、`retrieval-and-question-answering.md`、`../design/api-spec.md`

## 1. 用户目标

用户查看当前项目已入库资料，按集合或“未分组”筛选，并打开单份资料了解其内容与来源。

## 2. 当前可达

- 主界面通过 `LibraryModal` 提供“加入库”和“选择资料”两个步骤。
- 用户可查看全部资料、未分组资料和现有集合中的资料，并打开单份文档。
- 资料弹窗可读取 Obsidian 连接状态，并跳转到设置页管理连接。
- 集合、集合成员、文档列表和预览 API 均已实现。

## 3. 部分接线与不可达能力

- `LibraryModal` 只读取和筛选集合，不提供创建、改名、删除集合或调整成员关系；这些组件逻辑保留在未挂载的 `LibraryView`。
- 导入批次历史、项目状态、评估题库摘要等完整管理页信息也只在未挂载视图或 API 中保留。
- 在资料弹窗选择集合/文档不会写入当前回答请求，不能把该操作描述为已限制检索范围。
- URL 摘录卡片只提交 URL，尚未满足当前导入 helper 的标题/正文参数，属于部分接线。

## 4. 集合规则

- 集合只保存项目内的分组元数据和文档关联，不复制文档正文、chunk、向量或凭证。
- 同一集合中同一文档只能关联一次；集合和文档必须属于同一项目。
- 删除集合不删除文档；删除文档会清理其集合关联。
- 未分组视图表示没有任何集合关联的当前项目文档。

## 5. 边界

- 当前无文件夹树、拖拽排序、智能分类或跨项目集合。
- 项目备份/恢复的集合覆盖范围以当前 API 和 [`../design/database-design.md`](../design/database-design.md) 为准，不由界面推断。
