## 3. Decisions

- B-174 先建立默认关闭的后端 desktop mode，再接 Tauri 和数据运维；不把固定端口兼容行为误写成目标完成。
- 进程期桌面令牌只允许通过父进程环境和 Tauri 内存状态传递，不进入 CLI、日志、SQLite 或浏览器持久存储。
- 关联 ADR：ADR-018。
- 桌面进程令牌不是 Bearer/JWT；其 401 响应不发布 `WWW-Authenticate: Bearer`，避免客户端走错认证流程。
- 当前 Vue/CSP 仍固定 8765，安全 sidecar 必须保持 opt-in；动态 CSP 与生产入口切换不能在本阶段提前落地。
- 存储预检存在固有 TOCTOU，返回结果不是迁移授权或锁；复制、切换和恢复前必须重新执行同等校验。
- Python sqlite3 connection context 只管理事务、不自动关闭句柄；备份实现必须显式 closing，否则 Windows 会锁住 staging 数据库并阻断失败清理。
- 恢复不能直接做成普通同步路由；必须先增加请求排他门禁并协调 executor 停止，否则并发 API 或后台租约可能在 checkpoint/替换窗口继续写入。
- FastAPI 的装饰器 HTTP 中间件在流式响应发送完成前可能已经返回，不能用它统计完整 SSE 生命周期；恢复排他使用原生 ASGI 中间件，直到最后一个响应 body 发完才释放活动请求计数。
- PyInstaller 能分析到 Alembic Python 依赖，但不会自动收集以文件路径加载的 migration 目录和 `backend/alembic.ini`；sidecar 构建必须把二者作为 data 显式打包。
- PyInstaller onefile 在 Windows 上包含引导父进程与解包子进程；动态门禁不能只停止 `Start-Process -PassThru` 返回的 PID，必须在确认没有既有实例后按精确二进制路径清理本次进程树。
